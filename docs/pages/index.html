A reactive hash router.

Turn a folder of HTML templates into an app, with live data that survives reloads.

No dependencies, no build step — one script tag, about 1.6 KB gzipped.

Get started See examples

Features

rute does two things.

01 · Routes

Hash URLs to HTML templates

Every hash change loads the matching template and swaps it into the page — no reload. This site is built that way.

#/about  →  templates/about.html

02 · Binds

DOM elements to reactive values

Bound elements stay in sync, and their values persist in localStorage per route, across reloads.

<span data-bind="count">0</span>
<button onclick="count++">+1</button>
  • ↻Automatic persistence Bound values are saved to localStorage and restored on the next visit.
  • #/Scoped data Values are stored per route, so the same name on two pages holds two values.
  • ƒComputed values data-compute re-runs an expression like price * qty whenever a value it reads changes.
  • x=Plain globals Bound values are variables: write count++ in an onclick.
  • </>Scripts run Inline scripts in templates execute when the page loads.
  • ↗Any static host Templates are files fetched over HTTP, so GitHub Pages is enough.
