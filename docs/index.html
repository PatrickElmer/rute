A reactive hash router.

Turn a folder of HTML templates into an app, with live data that survives reloads.

No dependencies, no build step — one script tag, about 1.6 KB gzipped.

Get started See the full demo

Features

rute does two things.

01 · Routes

Hash URLs to HTML templates

On load and on every hashchange, rute fetches the matching template from a folder and swaps it into the page — no page reload. Scripts inside templates still run.

02 · Binds

DOM elements to reactive values

Values live in localStorage, scoped per route, so they survive reloads. Every bound element stays in sync, and computed expressions re-run when their inputs change.

Live demo

Two attributes for reactive data.

Add data-bind to make an element a live view of a value, and data-compute to turn its text into an expression. rute tracks the dependencies for you.

<input data-bind="price" value="10">
<input data-bind="qty" value="2">
<p>Total: <span data-compute="total">price * qty</span></p>

// Bound values are plain globals. Reset runs:
price = 10; qty = 2

How it works

From folder to app in three steps.

  1. Add the element and script

    <rute default="index" dir="templates/"></rute>
<script src="https://cdn.jsdelivr.net/gh/PatrickElmer/rute@main/rute.js"></script>

  2. Write plain HTML templates

    Visiting #/about fetches templates/about.html. No hash loads the default. No element? rute falls back to #rute, then document.body.

  3. Bind your data

    Each value is saved as rute_hash_<hash>_<name>, so the same name on two routes holds two values.

Examples

Small apps, one template each.

  • 0 Counter → count++
  • Todo list → persists per route
  • Dice → dice = 'Rolling…'

Good to know

  • Serve over HTTP in development (e.g. python3 -m http.server) — browsers block fetch() on file://.
  • data-compute runs through eval: keep expressions simple and trusted.
  • Bindings work best with strings, numbers and booleans.
  • No virtual DOM or components — made for simple, mostly-static sites that need a bit of shared state.
